# GPKG 全流程测试

入口：主页上方“GPKG 全流程测试”面板。按钮可左右滑动，标题可折叠面板。

## 使用内置数据验证

1. **创建点线面 GPKG**：GDAL 创建 EPSG:4326 的点、线、带洞面三个图层，每层一条要素，带 `name`、`number`、`value` 字段。关闭后重开核对数量及中文属性。
2. **读取信息**：显示文件位置、GDAL 版本、图层、字段类型/宽度/精度、数量、完整坐标系 WKT 和首条要素预览。
3. **加载地图**：由现有 ArcGIS Runtime 100.15.6 直接创建 GPKG FeatureLayer。
4. **选择要素**：先选图层，再点击地图上的点、线或面；状态栏显示选中要素信息。重叠要素会出现列表。
5. **编辑形状**：拖动节点，点线面分别测试。支持撤销；本测试拒绝修改 Z/M、真曲线及多点几何。
6. **编辑属性**：修改文本、短整数、整数、浮点数字段；勾选 NULL 与空字符串不同。“暂存”只改变草稿。
7. **保存修改**：ArcGIS 写回同一个 FID，释放 GPKG 后由 GDAL 独立重开检查属性，并显示落盘 WKT。ArcGIS 再次打开后校验几何一致性，并重新选中该要素。
8. **重开核验**：从磁盘重新检查元信息并加载地图。也可以退出应用、重新启动、加载地图，确认上次修改仍在。
9. **导出 SHP ZIP**：每张表导出一套 SHP，编码 UTF-8。关闭并重读，核对要素数、字段名称和坐标系。ZIP 包含配套文件及原图层名映射报告，可通过系统文件选择器另存。

“取消编辑”不写文件；“退出地图测试”移除测试图层并恢复业务地图点击操作。

“新增要素”向当前选中的点/线/面图层绘制新要素，填写属性后仍用“保存修改”提交；“删除要素”删除选中的工作副本要素，并关闭后重读核验删除结果。

## 用真实文件验证

- **SHP → GPKG**：系统选择 SHP 所在目录，然后选择一个数据集。要求同名 `.shp/.shx/.dbf/.prj`，存在 `.cpg` 时一并读取。先复制配套文件，再由 GDAL CopyLayer 转换，不经过旧 ShpModel 的图形/属性转换。
- **选择 GPKG**：将选择的完整文件复制为测试工作副本，检查可读后设为当前文件。请提供已经关闭、写入完成的 GPKG，不要选仍被其他应用写入的数据库。
- 所有编辑发生在应用的 `getExternalFilesDir()/gpkg_test` 目录（外部目录不可用时退回内部文件目录），不改所选源文件。
- 最近一次成功导入/创建的文件路径会保存。失败的测试目录保留，便于排查；不会覆盖历史测试结果。

## 推荐核验用例

| 用例 | 预期 |
| --- | --- |
| 点移位、线移动节点、带洞面移动节点 | 保存后几何一致性检查通过，重开位置正确，洞保留 |
| 中文文本、小数、NULL、空字符串 | 保存后重读一致；错误数值应阻止暂存 |
| 修改后取消 | 重开数据未改变 |
| 未保存就切换文件或导出 | 阻止操作，提示先保存或取消 |
| SHP 缺少 DBF/SHX/PRJ | 明确报错，原文件不变 |
| 选择非 GPKG 文件 | 检查失败，不切换当前工作文件 |
| 多部件线面、投影坐标系 SHP | 元信息保持，位置正确；用桌面 GIS 复核结构及精度 |
| 超长/重名字段或不支持的字段类型 | 导出明确报错，不静默生成字段映射 |
| 导出 ZIP 重新解压加载 | 每个图层要素数、属性和坐标正确，带洞面/多部件结构完整 |

## 本次边界

- GDAL 负责创建、SHP 转入、检查和 SHP 导出；ArcGIS 是编辑写入者。没有同时使用两个引擎写同一文件。编辑仍受实际 SDK 授权和表的可编辑能力约束，失败会显示原始错误。
- 包含点线面的新增、已有要素的形状/属性编辑和删除；不包含线面切割、拓扑联动、照片或样式持久化。
- SHP 导出的自动检查不等于完整无损检查：尚未逐条比较所有属性、几何和精度，请用桌面 GIS 复核。复杂字段暂不支持导出。
- 本机缺少 JDK，且 local.properties 的 Android SDK 路径指向不存在的旧机器目录，未完成 APK 编译及真机验证。XML 和入口绑定已静态检查，GDAL 使用的关键 API 已核对本地 gdal.jar。
